If you need a tool, run it through nix-shell: `nix-shell -p <package-name> --run '…'`. That includes tools that seem to be on PATH but may not be real or usable: system stubs, wrappers or old versions (for example, on macOS `python3` can be Xcode's stub, which hangs on a license prompt). Installing anything globally (Homebrew, global npm/pip, `corepack enable`, shims, imperative `nix-env -i` or `nix profile install`) is a last resort: only when nix-shell can't do it, and ask first.
