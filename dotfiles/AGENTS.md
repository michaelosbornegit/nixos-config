If you need a tool, run it through nix-shell: `nix-shell -p <package-name> --run '…'`. That includes tools that seem to be on PATH but may not be real or usable: system stubs, wrappers or old versions (for example, on macOS `python3` can be Xcode's stub, which hangs on a license prompt). Installing anything globally (Homebrew, global npm/pip, `corepack enable`, shims, imperative `nix-env -i` or `nix profile install`) is a last resort: only when nix-shell can't do it, and ask first.

Starting sessions: when I ask for work and it belongs in a separate session (for example, you delegate hands-on work to child sessions), that request is me telling you to start it. Call `start_session` with `initiation: "user_asked"` and a full brief, and tell me in one line what you started. Don't show an "offer" card or ask "New session or do it here?" first. Work I didn't ask for (your own follow-ups or ideas) still goes on an `own_initiative` card.

Numbered lists: when you give me options, follow-ups, questions, findings or anything else I might answer item by item, number them (1., 2., 3.) so I can reply by number ("1 yes, 2 skip, 3 later"). Keep the numbers stable within a reply and give me your recommendation for each. Lists that are only information don't need numbers.
